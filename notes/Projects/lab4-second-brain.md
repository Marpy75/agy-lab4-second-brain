# Лабораторна 4: Second Brain

## Короткий зміст
Проєктування та розробка локальної вебсистеми управління навчальними знаннями студента на чистому середовищі Node.js.

## Основні твердження
- Створення локальної системи персональних нотаток на платформі Node.js із повною відмовою від зовнішніх сторонніх бібліотек (zero-dependencies).
- Реалізація файлового сховища у форматі Markdown (`.md`) із метаданими YAML Frontmatter, структурованого за методологією PARA.
- Інтеграція з зовнішнім Agent Skill в Antigravity для автономного сортування, нормалізації тегів та класифікації вхідних нотаток із буфера Inbox.
