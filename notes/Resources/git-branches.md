# Гілки в Git

## Короткий зміст
Принципи галуження, створення й злиття гілок у Git, робота зі станом detached HEAD та особливості іменування гілки за замовчуванням.

## Основні твердження
- `git branch` — перегляд списку існуючих гілок або створення нової гілки.
- `git checkout -b` — створення нової гілки з одночасним переходом на неї.
- `git merge` — інтеграція змін із зазначеної гілки в поточну робочу гілку.
- Перехід на попередній коміт за хешем переводить репозиторій у стан detached HEAD (покажчик HEAD від'єднаний від гілки).
- Після команди `git init` типовою є проблема розбіжності імен основної гілки (`master` локально та `main` на GitHub), що потребує перейменування гілки перед синхронізацією.
