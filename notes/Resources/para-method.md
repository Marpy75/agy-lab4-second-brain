# Модель PARA

## Короткий зміст
Методологія структурування персональних знань і завдань за чотирма основними категоріями з використанням каталогу Inbox для швидкої фіксації.

## Основні твердження
- **Projects (Проєкти)** — короткострокові серії завдань із конкретно визначеними кінцевими термінами (дедлайнами).
- **Areas (Сфери)** — напрями діяльності та відповідальності без кінцевих термінів, що вимагають постійної підтримки стандартів (навчальні предмети, курси).
- **Resources (Ресурси)** — матеріали, теми інтересів, довідники та шпаргалки для постійного або майбутнього звернення.
- **Archives (Архіви)** — завершені, неактивні матеріали з інших трьох категорій або заархівовані конспекти.
- **Inbox (Вхідні)** — початковий буфер для швидкого збору сирих, ще не оброблених і не класифікованих нотаток перед їх розподілом за категоріями PARA.
