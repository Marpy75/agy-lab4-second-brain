# Основи Git

## Короткий зміст
Базові команди розподіленої системи контролю версій Git та особливості автентифікації на віддаленій платформі GitHub.

## Основні твердження
- `git init` — ініціалізує новий локальний репозиторій у поточній папці.
- `git clone` — створює локальну копію віддаленого репозиторію.
- `git status` — відображає стан робочого дерева та підготовлених до коміту файлів.
- `git add` — додає зміни файлів до індексу (staging area).
- `git commit` — фіксує проіндексовані зміни в історії версій із повідомленням.
- `git log` — виводить історію зафіксованих комітів.
- `git push` — відправляє локальні коміти у віддалений репозиторій.
- Для безпечної взаємодії з GitHub замість пароля облікового запису використовується персональний токен доступу (Personal Access Token).
