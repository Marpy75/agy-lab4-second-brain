# Bash-скрипти з параметрами

## Короткий зміст
Правила створення командних скриптів у середовищі Bash, обробка позиційних аргументів, цілочисельна арифметика та валідація вхідних даних.

## Основні твердження
- Shebang (`#!/bin/bash`) на першому рядку файлу вказує системі інтерпретатор для виконання скрипту.
- `$1`, `$2` — позиційні параметри, що передаються скрипту під час виклику; `$#` містить загальну кількість переданих аргументів.
- Арифметичні операції з цілими числами виконуються всередині конструкції `$(( ... ))`.
- `chmod +x` — надання файлу скрипту біта виконання перед запуском.
- Перед виконанням арифметичного ділення обов'язковою є перевірка знаменника на нуль для уникнення аварійного завершення скрипту.
