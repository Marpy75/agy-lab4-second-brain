# Користувачі та групи Linux

## Короткий зміст
Організація облікових записів, розподіл користувачів за групами та налаштування прав спільного доступу за допомогою спеціальних бітів у Linux.

## Основні твердження
- `groupadd` — створення нової групи користувачів у системі.
- `useradd -m -G` — створення нового користувача зі створенням домашньої директорії (`-m`) та додаванням до додаткових вторинних груп (`-G`).
- Кожен користувач має одну первинну групу (визначається при створенні) та може належати до кількох вторинних (supplementary) груп для надання додаткових прав.
- `id` — утиліта для перегляду UID (ідентифікатора користувача), GID (первинної групи) та списку всіх груп облікового запису.
- `chmod 2770` — встановлення прав читання, запису та виконання для власника і групи (без доступу іншим) із увімкненим бітом setgid (перша цифра 2).
- Біт setgid на каталозі гарантує, що всі новостворені файли всередині автоматично успадковують групу каталогу, а не первинну групу їх творця.
