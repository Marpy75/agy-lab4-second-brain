# Лабораторна 1: Git і GitHub

## Короткий зміст
Опанування практичних навичок роботи з розподіленою системою контролю версій Git та віддаленим хостингом репозиторіїв GitHub.

## Основні твердження
- Практичне освоєння роботи з локальним Git-клієнтом у терміналі (створення історії, фіксація та перегляд комітів).
- Налаштування автентифікації та робота з віддаленими репозиторіями на платформі GitHub.
- Роботу успішно виконано та переведено в завершений статус (archived).
