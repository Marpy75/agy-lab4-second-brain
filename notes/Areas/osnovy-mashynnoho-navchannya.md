# Основи машинного навчання: класифікація парадигм

Машинне навчання (Machine Learning) є підрозділом штучного інтелекту, що фокусується на розробці алгоритмів, які покращують якість виконання завдань на основі отриманого досвіду та емпіричних даних.

## Основні парадигми навчання

1. **Навчання з учителем (Supervised Learning):**
   - Модель навчається на розмічених парах «ознака — мітка» (features, labels).
   - Завдання: регресія (прогнозування неперервного значення) та класифікація (віднесення до класу).

2. **Навчання без учителя (Unsupervised Learning):**
   - Дані не містять міток; мета — знайти внутрішні закономірності чи приховану структуру.
   - Завдання: кластеризація (K-Means, DBSCAN), зниження розмірності (PCA, t-SNE).

3. **Навчання з підкріпленням (Reinforcement Learning):**
   - Агент взаємодіє із середовищем, максимізуючи сумарну винагороду.

## Базовий пайплайн підготовки та тренування

```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# Розподіл вибірки на тренувальну та валідаційну
X_train, X_test, y_train, y_test = train_test_split(
    features, labels, test_size=0.2, random_state=42
)

# Ініціалізація та тренування моделі
model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

# Оцінка точності
y_pred = model.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)
print(f"Точність моделі: {accuracy:.4f}")
```
