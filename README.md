# Персональний навчальний Second Brain (v2.0)

Локальна система управління знаннями (Second Brain) для студентів за методологією **PARA** (Inbox, Projects, Areas, Resources, Archives). Система побудована на принципах **Local-First**, збереженні конспектів у чистих Markdown-файлах (`.md`) із YAML Frontmatter, та повній відмові від сторонніх `npm`-залежностей і баз даних.

---

## 🛠 Архітектура та технологічний стек

- **Бекенд (Zero-Dependencies)**: Чистий Node.js із використанням лише вбудованих модулів (`http`, `fs`, `path`, `url`). Жодних сторонніх бібліотек з `npm`.
- **Локальна мережева ізоляція**: Сервер слухає виключно інтерфейс `127.0.0.1:3000` (localhost).
- **Сховище даних**: Файлова система ОС — директорія `notes/`, розбита на каталоги PARA.
- **Фронтенд**: Чистий HTML5, сучасний адаптивний CSS3 та Vanilla JavaScript (ES6+).
- **Безпека**:
  - **Path Traversal Protection**: суворий білий список категорій, заборона послідовностей `..`, `/`, `\`, обов'язкове розширення `.md`.
  - **Zero-DOMPurify XSS Protection**: власне надійне екранування HTML-сутностей.
  - **Soft Delete**: команда видалення не знищує файл фізично, а переміщує його в `notes/Archives/` зі встановленням `status: archived` після підтвердження користувача в модальному вікні.
- **Зв'язки між темами**: Підтримка двосторонніх посилань у форматі `[[Назва нотатки]]` з автоматичним розрахунком та відображенням списку зворотних посилань (**Backlinks**).
- **Підсвітка коду**: Власний синтаксичний аналізатор ключових слів для C/C++, JS/TS, Python тощо.

## 🚀 Швидкий запуск

### 1. Запуск застосунку
Переконайтеся, що на комп'ютері встановлено Node.js (версії 16+). У кореневій папці проєкту виконайте:

```powershell
npm start
```

Після запуску відкрийте браузер за адресою:
👉 **[http://127.0.0.1:3000](http://127.0.0.1:3000)**

### 2. Запуск автоматизованих тестів
Для перевірки захисту від Path Traversal, безпечного парсингу Frontmatter, розрахунку Backlinks та м'якого видалення виконайте:

```powershell
npm test
```

## 📋 Модель нотатки (YAML Frontmatter + Markdown)

Кожна нотатка у папці `notes/` має наступний вигляд:

```markdown
---
title: "Структурні конфлікти конвеєра"
created: "2026-11-01"

type: "lecture"
status: "in_progress"
tags:
  - "аскс"
  - "процесори"

## 💾 Інструкція з ручного резервного копіювання

Оскільки в системі свідомо відсутня небезпечна автосинхронізація з хмарою, збереження конспектів контролюється студентом одним із двох способів:

### Спосіб 1: Локальне або віддалене версіонування через Git (Рекомендовано)

1. Перевірте статус змін у навчальних нотатках:
   ```powershell
   git status
   ```
2. Зафіксуйте створені конспекти в локальний коміт:
   ```powershell
   git add notes/
   git commit -m "Конспекти лекцій за 01.11.2026"
   ```
3. (Опційно) Надішліть збережені зміни у свій приватний репозиторій:
   ```powershell
   git push origin second-brain-ver2
   ```

### Спосіб 2: Створення швидкого офлайн ZIP-архіву

У терміналі PowerShell у папці проєкту виконайте команду для створення резервної копії нотаток із поточною датою:

```powershell
Compress-Archive -Path notes -DestinationPath ("backup-notes-" + (Get-Date -Format "yyyy-MM-dd") + ".zip") -Force
```

Створений `.zip` файл можна зберегти на флеш-накопичувач або зовнішній диск.
